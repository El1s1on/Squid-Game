# Squid Game (Unity, WebGL)

Одиночная игра по мотивам «Игры в кальмара» в стиле Roblox для браузера. Сделана на **Unity 6 (6000.0)**, планировалась к выходу на платформе Яндекс Игры (через PluginYourGames).

> Статус: прототип, не завершён (последний коммит: август 2025). Реализованы несколько мини-игр и базовые системы.

## Что реализовано

**Мини-игры (отдельные сцены):**
- **Red Light, Green Light:** кукла со сменой света, определение движения игроков в зоне проверки, стрельба по нарушителям, таймер, безопасная зона.
- **Dalgona:** мини-игра с печеньем (есть бот для неё).
- **Hide and Seek:** прятки (заготовка, минимум кода).
- **Lobby и меню.**

**Боты (NavMesh):**
- Базовый класс бота и отдельные боты под каждую мини-игру.
- Три модели поведения: осторожный, агрессивный, глупый. Боты учитывают смену света, могут толкать других игроков.

**Игрок и системы:**
- Движение, камера, рэгдолл, здоровье, анимации.
- Инвентарь и предметы (нож, толчок), система интерактивных подсказок (proximity prompt).
- Контроллер игры, менеджер игроков, события.

## Где мой код

`Assets/Scripts` (около 3900 строк): `Games/`, `Bots/`, `Player/`, `Systems/`, `Proximity/`.
Папка `PluginYourGames` — стороннее SDK для платформ.

## Стек
Unity 6 · C# · NavMesh · DOTween · TextMeshPro · PluginYourGames (Яндекс Игры)

## Запуск
Открыть проект в Unity 6000.0.x и запустить сцену `Menu`.
